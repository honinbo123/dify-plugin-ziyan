# 隐私政策 · 紫烟数据分析

本插件在 Dify 本地插件容器内运行，处理用户上传的表格文件。

## 数据如何被处理

- 用户上传的 CSV / Excel 文件内容，仅在本插件容器的内存中被 pandas 解析、被 DuckDB 查询。
- 文件内容不会被写入容器的持久化磁盘，也不会被缓存到任何外部服务。
- 插件运行结束后，DataFrame 与 DuckDB 内存库随请求释放。
- 导出的 CSV 通过 Dify 的文件机制返回给用户，插件侧不保留副本。

## 网络访问

本插件不发起任何外部网络请求，不包含遥测、不收集使用统计。

## 凭据

本插件不需要任何 API Key 或第三方账号凭据。

## 第三方依赖

pandas、openpyxl、duckdb 均为本地计算库，不上传数据。
